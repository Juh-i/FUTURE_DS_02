## Key Insights

- Month-to-month customers showed the highest churn rate.
- Long-term contracts improved customer retention.
- Customers with shorter tenure were more likely to churn.
- High-value customers contributed significant revenue loss when churning.

## Business Recommendations

- Improve customer onboarding.
- Encourage long-term contracts.
- Implement retention campaigns for high-risk customers.
- Strengthen customer support engagement.
